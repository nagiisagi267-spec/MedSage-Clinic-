# MedSage Clinic - Premium Healthcare & Wellness Center

A modern, responsive, and interactive website for MedSage Clinic, providing comprehensive medical care, wellness services, doctor appointments, and patient portal access.

## Features
- **Responsive Navigation & Hero Section**: Clean modern design with quick action links and appointment booking.
- **Specialized Medical Services**: Cardiology, Neurology, Pediatrics, Orthopedics, and Diagnostic Labs.
- **Interactive Appointment Booking Form**: Live validation with specialty and doctor selection.
- **Doctor Profiles & Testimonials**: Comprehensive team showcase and patient reviews.
- **Emergency & Contact Information**: Fast access to emergency assistance and clinic location.

## Technology Stack
- HTML5 (Semantic & Accessible)
- CSS3 (Custom Design System, Flexbox, CSS Grid, Responsive)
- JavaScript (Interactive Components, Form Validation, Modal Dialogs)

## Getting Started
To view the site locally:
1. Double click `index.html` to open directly in any browser, or
2. Run `server.ps1` in PowerShell to run a local HTTP server at `http://localhost:8080/`.
